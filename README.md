# 🌐 Personal Website

A simple personal website created as a learning project while studying HTML.

This project was developed to practice basic HTML concepts and gain hands-on experience in web development.

## ✨ Features

- Multiple HTML pages
- Basic website structure
- Navigation between pages
- Images and links
- Basic HTML elements

## 🛠️ Technologies

- HTML5

## 📚 Learning Goals

The main purpose of this project was to practice the HTML concepts I had learned and understand how web pages are structured.

Through this project, I gained practical experience in:

- Creating HTML documents
- Using headings, paragraphs, lists, and links
- Working with images
- Creating multiple pages
- Organizing website files and folders

## 🚀 Project Status

This project is a beginner-level learning project and may be improved with additional features and styling in the future.

It represents one of my first steps in learning web development.
